# Currency Converter

A modern and responsive Currency Converter built with React and Tailwind CSS. It allows users to quickly convert between different currencies using real-time exchange rates.

## 🚀 Live Demo

[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-Visit_Website-blue?style=for-the-badge)](https://exchange-rate-hub.vercel.app/)



## Features

* Real-time currency conversion
* Supports multiple international currencies
* Currency search and selection
* Country flags for currencies
* Responsive design for mobile, tablet, and desktop
* Clean and modern UI
* Fast and lightweight

## Installation

1. Clone the repository:

```bash
git clone https://github.com/nageshl-12/-Currency-Converter-
```

2. Navigate to the project folder:

```bash
cd currency-converter
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
